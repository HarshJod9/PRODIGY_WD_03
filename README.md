# PRODIGY_WD_03 — Tic-Tac-Toe Web Application

A responsive tic-tac-toe game with local two-player and computer modes.

## Run

Open `index.html` in a browser. No build step or dependencies are required.

## Features

- Clickable 3 × 3 board with turn and win-state handling
- Two-player mode and a minimax computer opponent
- Score tracking, new round and score reset
- Highlighted winning line, draw state and optional sound cues
- Keyboard-operable buttons and live status announcements
